# Laravel REST API

A production-style REST API built with Laravel 12, demonstrating clean backend architecture, authentication, validation, API resources, Eloquent relationships, pagination, and structured error handling.

## 🚀 Features

- RESTful API architecture
- User authentication
- API request validation
- API Resources
- Eloquent relationships
- Pagination
- Consistent JSON responses
- Exception and error handling
- Database migrations and seeders
- Feature and API testing
- Clean and maintainable Laravel structure

## 🛠️ Tech Stack

- PHP 8.2+
- Laravel 12
- MySQL
- Eloquent ORM
- Laravel Sanctum
- PHPUnit
